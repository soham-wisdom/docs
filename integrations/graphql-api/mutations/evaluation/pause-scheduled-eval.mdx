---
title: "Pause Scheduled Eval"
---

The `pauseScheduledEval` mutation pauses the schedule of an evaluation set. It requires the `evaluation:schedule` permission, and the `evaluation:lock` permission if the set is locked.

## Signature

```graphql
pauseScheduledEval(domainId: String!, evalSetId: String!): Boolean!
```

| Argument | Type | Description |
| :-- | :-- | :-- |
| `domainId` | `String!` | The domain that contains the evaluation set. |
| `evalSetId` | `String!` | The evaluation set whose schedule to pause. |

Returns `true` if the schedule was paused.

## Example

```graphql
mutation PauseScheduledEval($domainId: String!, $evalSetId: String!) {
  pauseScheduledEval(domainId: $domainId, evalSetId: $evalSetId)
}
```

```json Variables
{ "domainId": "domain_987654321", "evalSetId": "eval_set_123" }
```

```json Response
{ "data": { "pauseScheduledEval": true } }
```
