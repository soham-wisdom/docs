---
title: "Update Eval Set"
---

The `updateEvalSet` mutation updates an evaluation set. The `items` argument replaces the whole list of sessions, so pass every session you want to keep.

## Signature

```graphql
updateEvalSet(input: UpdateEvalSetInput!): EvalSet!
```

[Note: Need clarification on the name of the input type. `UpdateEvalSetInput` is used here as a working name.]

<Note>
  This mutation requires the `evaluation:write` permission on the domain. Updating a locked evaluation set also requires the `evaluation:lock` permission.
</Note>

## Arguments

<ParamField path="input" type="UpdateEvalSetInput!" required>
  Input object containing the update. See [UpdateEvalSetInput](#updateevalsetinput).
</ParamField>

### UpdateEvalSetInput

<ParamField path="id" type="ID!" required>
  The ID of the evaluation set to update.
</ParamField>

<ParamField path="domainId" type="String!" required>
  The ID of the domain that the evaluation set belongs to.
</ParamField>

<ParamField path="items" type="[[PromptSQLPairInput!]!]!" required>
  The sessions of the evaluation set. This list replaces the existing sessions. Each turn takes the same shape as [PromptSQLPair](/integrations/graphql-api/objects/prompt-sql-pair#input-shape).
</ParamField>

<ParamField path="name" type="String">
  The new name of the evaluation set.
</ParamField>

<ParamField path="customGradingInstructions" type="String">
  The new custom grading instructions for the evaluation set.
</ParamField>

## Response

Returns the updated `EvalSet` object. See [EvalSet](/integrations/graphql-api/objects/eval-set) for the schema.

## Usage example

This example renames an evaluation set and replaces its sessions:

```graphql
mutation UpdateEvalSet($input: UpdateEvalSetInput!) {
  updateEvalSet(input: $input) {
    id
    name
    version
    caseIds
  }
}
```

<RequestExample>

```bash Request
curl -X POST \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <jwt_token>" \
  -d '{
    "query": "mutation UpdateEvalSet($input: UpdateEvalSetInput!) { updateEvalSet(input: $input) { id name version caseIds } }",
    "variables": {
      "input": {
        "id": "eval_set_123",
        "domainId": "domain_987654321",
        "name": "Revenue questions v2",
        "items": [
          [
            {
              "prompt": "What is the total revenue for closed won opportunities?",
              "sql": ["SELECT SUM(amount) FROM Opportunity WHERE stage = '\''Closed Won'\''"]
            }
          ]
        ]
      }
    }
  }' \
  https://{ACCOUNT}.askwisdom.ai/graphql
```

</RequestExample>

<ResponseExample>

```json Response
{
  "data": {
    "updateEvalSet": {
      "id": "eval_set_123",
      "name": "Revenue questions v2",
      "version": 2,
      "caseIds": ["case_001"]
    }
  }
}
```

</ResponseExample>
