---
title: "Set Eval Set Locked"
---

The `setEvalSetLocked` mutation locks or unlocks an evaluation set. It requires the `evaluation:read` and `evaluation:lock` permissions. Updating, deleting, rescheduling, or pausing the schedule of a locked set also requires `evaluation:lock`.

## Signature

```graphql
setEvalSetLocked(domainId: ID!, evalSetId: ID!, isLocked: Boolean!): EvalSet!
```

| Argument | Type | Description |
| :-- | :-- | :-- |
| `domainId` | `ID!` | The domain the evaluation set belongs to. |
| `evalSetId` | `ID!` | The evaluation set to lock or unlock. |
| `isLocked` | `Boolean!` | `true` locks the set and `false` unlocks it. |

Returns the updated [EvalSet](/integrations/graphql-api/objects/evaluation-data-types#evalset).

## Example

```graphql
mutation SetEvalSetLocked($domainId: ID!, $evalSetId: ID!, $isLocked: Boolean!) {
  setEvalSetLocked(domainId: $domainId, evalSetId: $evalSetId, isLocked: $isLocked) {
    id
    isLocked
  }
}
```

```json Variables
{ "domainId": "domain_987654321", "evalSetId": "eval_set_123", "isLocked": true }
```

```json Response
{ "data": { "setEvalSetLocked": { "id": "eval_set_123", "isLocked": true } } }
```
