---
title: "Set Eval Set Locked"
---

The `setEvalSetLocked` mutation locks or unlocks an evaluation set. Updating, deleting, or rescheduling a locked set requires the `evaluation:lock` permission.

## Signature

```graphql
setEvalSetLocked(domainId: String!, evalSetId: ID!, isLocked: Boolean!): EvalSet!
```

[Note: Need clarification on the exact GraphQL argument types. The types shown are inferred.]

<Note>
  This mutation requires both the `evaluation:read` and `evaluation:lock` permissions on the domain.
</Note>

## Arguments

<ParamField path="domainId" type="String!" required>
  The ID of the domain that the evaluation set belongs to.
</ParamField>

<ParamField path="evalSetId" type="ID!" required>
  The ID of the evaluation set to lock or unlock.
</ParamField>

<ParamField path="isLocked" type="Boolean!" required>
  Pass `true` to lock the evaluation set and `false` to unlock it.
</ParamField>

## Response

Returns the updated `EvalSet` object. See [EvalSet](/integrations/graphql-api/objects/eval-set) for the schema.

## Usage example

```graphql
mutation SetEvalSetLocked($domainId: String!, $evalSetId: ID!, $isLocked: Boolean!) {
  setEvalSetLocked(domainId: $domainId, evalSetId: $evalSetId, isLocked: $isLocked) {
    id
    isLocked
  }
}
```
