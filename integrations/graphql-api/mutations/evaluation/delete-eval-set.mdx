title: "Delete Eval Set"
---

The `deleteEvalSet` mutation deletes an evaluation set.

## Signature

```graphql
deleteEvalSet(input: DeleteEvalSetInput!): Boolean!
```

[Note: Need clarification on the name of the input type. `DeleteEvalSetInput` is used here as a working name.]

<Note>
  This mutation requires the `evaluation:write` permission on the domain. Deleting a locked evaluation set also requires the `evaluation:lock` permission.
</Note>

## Arguments

<ParamField path="input" type="DeleteEvalSetInput!" required>
  Input object identifying the evaluation set. See [DeleteEvalSetInput](#deleteevalsetinput).
</ParamField>

### DeleteEvalSetInput

<ParamField path="id" type="ID!" required>
  The ID of the evaluation set to delete.
</ParamField>

<ParamField path="domainId" type="String!" required>
  The ID of the domain that the evaluation set belongs to.
</ParamField>

## Response

Returns `true` if the evaluation set was deleted.

## Usage example

```graphql
mutation DeleteEvalSet($input: DeleteEvalSetInput!) {
  deleteEvalSet(input: $input)
}
```

