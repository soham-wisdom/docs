---
title: "Delete Eval Set"
---

The `deleteEvalSet` mutation deletes an evaluation set. It requires the `evaluation:write` permission, and the `evaluation:lock` permission if the set is locked.

## Signature

```graphql
deleteEvalSet(input: DeleteEvalSetInput!): Boolean!
```

`DeleteEvalSetInput` fields:

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `ID!` | The evaluation set to delete. |
| `domainId` | `ID!` | The domain the evaluation set belongs to. |

Returns `true` if the evaluation set was deleted.

## Example

```graphql
mutation DeleteEvalSet($input: DeleteEvalSetInput!) {
  deleteEvalSet(input: $input)
}
```

```json Variables
{ "input": { "id": "eval_set_123", "domainId": "domain_987654321" } }
```

```json Response
{ "data": { "deleteEvalSet": true } }
```
