---
title: "Evaluation Run Group"
---

The `evaluationRunGroup` query returns the individual runs that one `runEvaluation` call started. It requires the `evaluation:read` permission.

## Signature

```graphql
evaluationRunGroup(runGroupId: ID!): EvaluationRunGroup!
```

| Argument | Type | Description |
| :-- | :-- | :-- |
| `runGroupId` | `ID!` | The run group ID that `runEvaluation` returned. It is a run group ID, not a run ID, even when `runCount` is 1. |

Returns an [EvaluationRunGroup](/integrations/graphql-api/objects/evaluation-data-types#evaluationrungroup) object. Pass a run ID to [evaluationRun](/integrations/graphql-api/queries/evaluation/evaluation-run) to get one run in full.

## Example

```graphql
query EvaluationRunGroup($runGroupId: ID!) {
  evaluationRunGroup(runGroupId: $runGroupId) {
    runs {
      id
      completedAt
      overallCombinedScore
    }
  }
}
```

```json Variables
{ "runGroupId": "run_group_789" }
```

```json Response
{
  "data": {
    "evaluationRunGroup": {
      "runs": [
        {
          "id": "run_456",
          "completedAt": "2026-11-19T10:42:00Z",
          "overallCombinedScore": 0.92
        }
      ]
    }
  }
}
```
