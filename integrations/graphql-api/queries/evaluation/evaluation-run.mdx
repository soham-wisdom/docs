---
title: "Evaluation Run"
---

The `evaluationRun` query returns one evaluation run, with the score and result for each turn. It requires the `evaluation:read` permission.

## Signature

```graphql
evaluationRun(id: ID!): EvaluationRun!
```

| Argument | Type | Description |
| :-- | :-- | :-- |
| `id` | `ID!` | The ID of the run. To get the run IDs of one `runEvaluation` call, use [evaluationRunGroup](/integrations/graphql-api/queries/evaluation/evaluation-run-group). |

Returns an [EvaluationRun](/integrations/graphql-api/objects/evaluation-data-types#evaluationrun) object.

## Example

```graphql
query EvaluationRun($id: ID!) {
  evaluationRun(id: $id) {
    id
    overallCombinedScore
    promptPairs {
      prompt
    }
    evaluations {
      softEvalScore
      softEvalFeedback
      manualScore
      assertionResults {
        assertionId
        verdict
        reasoning
      }
    }
  }
}
```

```json Variables
{ "id": "run_456" }
```
