title: "Evaluation Run"
---

The `evaluationRun` query returns one evaluation run, including the turns as they were when the run happened and the score and result for each turn.

## Signature

```graphql
evaluationRun(id: ID!): EvaluationRun!
```

[Note: Need clarification on the exact GraphQL argument and return types. The types shown are inferred.]

<Note>
  This query requires the `evaluation:read` permission on the domain.
</Note>

## Arguments

<ParamField path="id" type="ID!" required>
  The ID of the evaluation run. To get the IDs of the runs that one `runEvaluation` call started, use [evaluationRunGroup](/integrations/graphql-api/queries/evaluation/evaluation-run-group).
</ParamField>

## Response

Returns an `EvaluationRun` object. See [EvaluationRun](/integrations/graphql-api/objects/evaluation-run) for the schema.

## Usage example

This example retrieves the scores and feedback of each turn in a run:

```graphql
query EvaluationRun($id: ID!) {
  evaluationRun(id: $id) {
    id
    evalSetName
    overallCombinedScore
    promptPairs {
      prompt
    }
    evaluations {
      softEvalScore
      softEvalFeedback
      manualScore
      assertionResults {
        assertionId
        verdict
        reasoning
      }
    }
  }
}
```
