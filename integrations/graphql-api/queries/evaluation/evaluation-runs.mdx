---
title: "Evaluation Runs"
---

The `evaluationRuns` query lists evaluation runs, with optional filtering by evaluation set or domain. It requires the `evaluation:read` permission.

## Signature

```graphql
evaluationRuns(filter: EvaluationRunsFilterInput!, offset: Int, limit: Int): [EvaluationRunSummary!]!
```

| Argument | Type | Description |
| :-- | :-- | :-- |
| `filter` | `EvaluationRunsFilterInput!` | The filter to apply. You must pass it, but every field in it is optional. |
| `offset` | `Int` | The number of runs to skip. |
| `limit` | `Int` | The maximum number of runs to return. |

`EvaluationRunsFilterInput` fields:

| Field | Type | Description |
| :-- | :-- | :-- |
| `evaluationSetIds` | `[ID!]` | Return only runs of these evaluation sets. |
| `domainIds` | `[String!]` | Return only runs in these domains. [Note: Need clarification on the type of `domainIds`.] |
| `fullRunsOnly` | `Boolean` | Set to `true` to skip targeted runs, which are runs that used `evaluationCaseIds`. |

Returns a list of [EvaluationRunSummary](/integrations/graphql-api/objects/evaluation-data-types#evaluationrunsummary) objects.

## Example

```graphql
query EvaluationRuns($filter: EvaluationRunsFilterInput!, $limit: Int) {
  evaluationRuns(filter: $filter, limit: $limit) {
    id
    evalSetName
    createdAt
    completedAt
    completedConversationCount
    totalConversationCount
    overallCombinedScore
  }
}
```

```json Variables
{
  "filter": { "evaluationSetIds": ["eval_set_123"], "fullRunsOnly": true },
  "limit": 10
}
```

      }

}
