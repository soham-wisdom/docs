---
title: "Eval Sets"
---

The `evalSets` query returns the evaluation sets of a domain. It requires the `evaluation:read` permission.

## Signature

```graphql
evalSets(domainId: ID!, draftId: ID): [EvalSet!]!
```

| Argument | Type | Description |
| :-- | :-- | :-- |
| `domainId` | `ID!` | The domain to return evaluation sets for. |
| `draftId` | `ID` | A draft of the domain. The response also includes the sets staged on that draft. |

Returns a list of [EvalSet](/integrations/graphql-api/objects/evaluation-data-types#evalset) objects.

## Example

```graphql
query EvalSets($domainId: ID!) {
  evalSets(domainId: $domainId) {
    id
    name
    version
    isLocked
    caseIds
    items {
      prompt
      sql
    }
  }
}
```

```json Variables
{ "domainId": "domain_987654321" }
```

```json Response
{
  "data": {
    "evalSets": [
      {
        "id": "eval_set_123",
        "name": "Revenue questions",
        "version": 2,
        "isLocked": false,
        "caseIds": ["case_001"],
        "items": [
          [
            {
              "prompt": "What is the total revenue for closed won opportunities?",
              "sql": ["SELECT SUM(amount) FROM Opportunity WHERE stage = 'Closed Won'"]
            }
          ]
        ]
      }
    ]
  }
}
```
