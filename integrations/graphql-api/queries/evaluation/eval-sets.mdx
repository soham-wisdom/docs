---
title: "Eval Sets"
---

The `evalSets` query returns the evaluation sets of a domain, with their sessions and turns, version, lock state, and schedule.

## Signature

```graphql
evalSets(domainId: String!, draftId: ID): [EvalSet!]!
```

[Note: Need clarification on the exact GraphQL argument types. The types shown are inferred from the `EvalSet` schema.]

<Note>
  This query requires the `evaluation:read` permission on the domain.
</Note>

## Arguments

<ParamField path="domainId" type="String!" required>
  The ID of the domain to return evaluation sets for.
</ParamField>

<ParamField path="draftId" type="ID">
  The ID of a draft of the domain. When you pass it, the response also includes the evaluation sets staged on that draft.
</ParamField>

## Response

Returns a list of `EvalSet` objects. See [EvalSet](/integrations/graphql-api/objects/eval-set) for the schema.

## Usage example

This example lists the evaluation sets of a domain, with their schedule:

```graphql
query EvalSets($domainId: String!) {
  evalSets(domainId: $domainId) {
    id
    name
    version
    isLocked
    caseIds
    cronExpression
    cronTimezone
    scheduledRunChatMode
    items {
      prompt
      sql
    }
  }
}
```

<RequestExample>
