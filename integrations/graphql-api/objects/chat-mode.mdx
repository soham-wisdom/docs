This page describes the `ChatMode` enum, which sets how WisdomAI answers the prompts in an evaluation run.

## ChatMode

| Value | Description |
| --- | --- |
| `FAST` | Answers quickly. Scheduled runs use this mode by default. |
| `NORMAL` | Balances speed and depth. Runs that you start with `runEvaluation` use this mode by default. |
| `DEEP_THINK` | Applies more effort to each answer. |
