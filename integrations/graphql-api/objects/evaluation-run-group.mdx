This page describes the `EvaluationRunGroup` object, which groups the runs that one `runEvaluation` call starts. A call always returns a run group ID, even when `runCount` is 1.

[Note: Need clarification on the GraphQL type name of the object that `evaluationRunGroup` returns. `EvaluationRunGroup` is used here as a working name.]

## EvaluationRunGroup

<ParamField path="runs" type="[EvaluationRun!]!" required>

</ParamField>
