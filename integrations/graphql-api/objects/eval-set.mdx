---
title: "Eval Set"
---

This page describes the `EvalSet` object, which represents an evaluation set in a domain: its sessions and turns, version, lock state, and schedule.

## EvalSet

<ParamField path="id" type="ID!" required>
  Unique identifier for the evaluation set.
</ParamField>

<ParamField path="name" type="String!" required>
  The name of the evaluation set.
</ParamField>

<ParamField path="domainId" type="String!" required>
  The ID of the domain the evaluation set belongs to.
</ParamField>

<ParamField path="version" type="Int!" required>
  The version of the evaluation set.
</ParamField>

<ParamField path="isLocked" type="Boolean!" required>
  Whether the evaluation set is locked. Updating, deleting, or rescheduling a locked set requires the `evaluation:lock` permission.
</ParamField>

<ParamField path="items" type="[[PromptSQLPair!]!]!" required>
  The sessions of the evaluation set. Each session is an ordered list of turns. See [PromptSQLPair](/integrations/graphql-api/objects/prompt-sql-pair).
</ParamField>

<ParamField path="caseIds" type="[ID!]!" required>
  One ID per session, in the same order as `items`. Pass these IDs to `evaluationCaseIds` in `runEvaluation` to run specific cases.
</ParamField>

<ParamField path="customGradingInstructions" type="String">
  Custom grading instructions that apply to the whole evaluation set.
</ParamField>

<ParamField path="cronExpression" type="String">
  The cron expression of the schedule. Null when the evaluation set is not scheduled.
</ParamField>

<ParamField path="cronTimezone" type="String">
  The time zone of the cron expression.
</ParamField>

<ParamField path="scheduledRunChatMode" type="ChatMode">
  The chat mode that scheduled runs use. See [ChatMode](/integrations/graphql-api/objects/chat-mode).
</ParamField>

<ParamField path="draftId" type="ID">
  The ID of the domain draft the evaluation set is staged on. The set goes live when the draft is published.
</ParamField>

<ParamField path="createdAt" type="DateTime!" required>
  Timestamp when the evaluation set was created.
</ParamField>

<ParamField path="updatedAt" type="DateTime!" required>
  Timestamp when the evaluation set was last updated.
</ParamField>
