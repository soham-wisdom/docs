This page describes the `EvaluationRun` object, which represents one evaluation run with the turns as they were when the run happened and the result for each turn.

## EvaluationRun

`EvaluationRun` has the same fields as [EvaluationRunSummary](/integrations/graphql-api/objects/evaluation-run-summary), except `completedConversationCount` and `totalConversationCount`, which exist only on `EvaluationRunSummary`. It adds the following fields.

<ParamField path="promptPairs" type="[[PromptSQLPair!]!]!" required>
  The turns as they were when the run happened. See [PromptSQLPair](/integrations/graphql-api/objects/prompt-sql-pair).
</ParamField>

<ParamField path="evaluations" type="[[PromptEvaluation!]!]">
  One result per turn, in the same shape as `promptPairs`. See [PromptEvaluation](/integrations/graphql-api/objects/prompt-evaluation).
</ParamField>
