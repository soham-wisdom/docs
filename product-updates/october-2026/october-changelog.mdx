<Update label="Updates">

  ### 🦉 Owls

  Owls are AI analysts that work on a goal in the background. WisdomAI is building them with a small group of design partners. See [Owls](/early-access/owls) to learn what an Owl does and how to become a design partner.

  <Note>
    Owls are in alpha.
  </Note>

  ### 🔒 Column-level security on derived columns

  CLS on a base column now applies automatically to every derived column that references it, so you don't need to configure anything extra on the derived column. To protect a derived column, apply CLS to each base column it references. See [Column-level security](/manage-account/row-level-access-control/column-level-security-cls).

  ### 🔌 Connection management and settings

  New guides explain how WisdomAI checks, runs, and monitors your connections, so you can manage them with confidence.

  **⚙️ How it works:**

  - **Manage connections:** WisdomAI checks a connection when you save it and tells you how to fix anything that fails. From the Connections list, you can sync a connection, review its run logs, set up alerts, or remove it
  - **Advanced settings:** Limit how long queries run and how much data they scan, and use different credentials for different users
  - **Access:** Let WisdomAI read query history and system metadata so it can monitor performance and plan more efficient queries
  - **How WisdomAI queries your warehouse:** See when WisdomAI reuses an earlier result and how to recognize its queries in your warehouse's query history

  ### 🗄️ New connection types and sign-in options

  [Supported Data Sources](/getting-started/connect-data-sources/supported-data-sources) now covers more sources and ways to sign in.

  **⚙️ How it works:**

  - **New sources:** Connect **MySQL**, **Oracle**, **Amazon S3**, **MotherDuck**, and **Tableau**. Access **Connections** > **Add connection**, select the source, enter its details, and save
  - **Calendars:** Connect **Google Calendar** and **Outlook Calendar**. Each person then connects their own calendar under [Connected Apps](/settings/connected-apps), and agents can start a run from calendar events with the [Calendar trigger](/setting-up-wisdom-ai/agents/nodes-reference)
  - **Snowflake OAuth:** Each person's questions can run under their own Snowflake login through your identity provider, while WisdomAI keeps using the service user for crawls and validation. See [Connect to Snowflake](/getting-started/connect-data-sources/connect-to-snowflake)
  - **MCP servers:** Sign in with None, API Key, OAuth, or Azure Service Principal, connect STDIO servers, and adjust how long WisdomAI waits for a response. See [Connect an MCP server](/getting-started/connect-data-sources/connect-mcp-server)

  ### 🏗️ Context Builder sources

  [Context Builder](/product-updates/spring-2026/context-builder-connections) now lists more sources.

  **⚙️ How it works:**

  - **GitLab and Azure DevOps:** Attach a repository the same way as GitHub, choose which paths to include, and optionally rebuild it daily
  - **Tableau:** Pull metric and field definitions from Tableau workbooks
  - **Query logs:** Build from query logs for Snowflake, BigQuery, Redshift, ClickHouse, and Databricks

  ### 📚 Connection documentation improvements

  The connection guides now match the current product.

  - **Supported data sources**: Reorganized into Warehouse & Database, File & Repository, BI tools, and Calendars. CSV files and direct uploads are described as uploads to a domain rather than connections.
  - **Connection setup guides**: [Databricks](/getting-started/connect-data-sources/connect-to-databricks), [Google BigQuery](/getting-started/connect-data-sources/connect-to-google-bigquery), [Amazon Redshift](/getting-started/connect-data-sources/connect-to-amazon-redshift), and [SharePoint](/getting-started/connect-data-sources/connect-to-sharepoint) follow the current setup flow.
  - **Data source management**: The [Quickstart](/setting-up-wisdom-ai/basic-tutorial-connect-and-test) and the [Data Sources tab](/setting-up-wisdom-ai/manage-domains/data-sources-tab) reflect how sources are added and organized in a domain.
  - **API reference**: The [Connection object](/integrations/graphql-api/objects/connection) lists the current connection and data source types.
  - **Corrected information**: Updated settings and examples across the supported connections, and removed outdated details, including options that aren't offered.

  ### 🏷️ Outdated Alpha and Beta labels removed

  Outdated Alpha and Beta labels are removed from the Agents, Skills, and Knowledge Signals pages.
