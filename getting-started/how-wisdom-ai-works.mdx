WisdomAI turns your business data into answers, Dashboards, and Live Apps through a multi-layered pipeline. Each layer builds on the one before it, and user feedback flows back into the semantic model so answers keep improving. Select a step to see what happens there.

<DataFlowDiagram />

<Accordion title="All steps at a glance" icon="list-ol">
  1. **Connected Data Sources:** WisdomAI integrates with your data platforms (such as Snowflake, BigQuery, or Redshift), serving as the entry point for all information flowing through the system.
  2. **Semantic Modeling:** Admins and data owners enrich the data by documenting tables, columns, and domains, and by defining relationships to create a business-friendly context for natural language understanding.
  3. **Natural Language Query Engine:** Users ask questions in plain language. The engine parses each question and translates it into SQL using the semantic model.
  4. **Dashboards and Live Apps:** Answers become interactive Dashboards that combine visualizations, text, and insights, or Live Apps that WisdomAI generates from a prompt on your governed data. Both refresh on a schedule and can be shared.
  5. **Delivery and Reporting:** Dashboards can be delivered on a schedule via email. Dashboards and Live Apps can be embedded into external applications, so teams stay informed with minimal effort.
  6. **User Feedback and Corrections:** Users give feedback on answer accuracy, suggest corrections, or add clarifying context to improve future results.
  7. **Knowledge Updates and Review:** Admins review user feedback and update the semantic layer, closing the loop and continuously improving answer quality.
</Accordion>
