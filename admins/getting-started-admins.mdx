title: "Getting Started for Admins"
---

As an Admin, you set up the foundation that every answer in WisdomAI depends on: the data it can reach, the context that explains it, and the rules for who can see what. This page walks you through the setup path and points to the guides you will use most.

## Set up WisdomAI in 5 steps

<Steps>
  <Step icon="plug" title="Connect your data">
    Link your data warehouse or other sources so WisdomAI can query them. See [supported data sources](/getting-started/connect-data-sources/supported-data-sources).
  </Step>
  <Step icon="database" title="Create a domain and add context">
    Group your tables into a domain, then describe tables, columns, and metrics so answers match how your business talks. See [Getting started with domains and context](/setting-up-wisdom-ai/getting-started-domains-context).
  </Step>
  <Step icon="vial" title="Test and improve answers">
    Validate responses and track quality with evaluation sets. See [Validate and test answers](/improve-wisdom-ai-responses/validate-and-test-answers).
  </Step>
  <Step icon="shield-check" title="Control access">
    Decide who can see which data with row-level and column-level security. See [Row-level access control](/manage-account/row-level-access-control/row-level-access-control).
  </Step>
  <Step icon="users" title="Onboard your Explorers">
    Configure starter questions, the prompt gallery, and autocomplete. See [Explorer onboarding admin setup](/setting-up-wisdom-ai/explorer-onboarding-admin-setup).
  </Step>
</Steps>
