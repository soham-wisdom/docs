---
title: "Libraries"
---

Knowledge items live inside the Domain where you created them. Libraries let you move Knowledge out of a single Domain and into a shared collection that can be reused across multiple Domains.

Working with Libraries involves two steps: moving Knowledge into a Library, and then linking that Library to the Domains that should use it.

### Move Knowledge to a Library

1. From the **Knowledge** tab, select the item you want to reuse and click **Move to Library Icon**.

### Link a Library to a Domain

A Library's Knowledge is only available for AI queries in Domains it's linked to. To link one or more Libraries to a Domain:

1. From the Domain's **Context** tab, open the option to **Link Libraries to Domain**.

  <img
    alt="NEW Add Knowledge Steps"

2. Open the **Libraries** dropdown and select the Library or Libraries you want linked.
3. Click **Save**.

Once linked, any Knowledge stored in that Library is available for query interpretation in the Domain, alongside the Domain's own Knowledge.
