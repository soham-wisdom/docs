title: "Domain Groups"
---

A domain group combines multiple domains so you can query them together. This page explains why domain groups exist, then shows you how to create one, add cross-domain context, and work with cross-domain reviewed queries.

## Why it matters

Domains keep data and context isolated from each other by design, so each one stays scoped to a single business area and its own access permissions. Plenty of real questions cut across that boundary, though, like comparing marketing spend in one domain against revenue booked in another. Querying each domain on its own and combining the results by hand is slow, and it leaves whoever runs the query responsible for knowing how the domains relate.

A domain group solves the first part of that problem: it lets you run one query against several domains at once, while WisdomAI still uses each domain's own context to interpret its part of the answer.

The second part is relationships between domains. A domain's own context explains that domain's data, not how its metrics line up with another domain's. A domain group adds a separate context layer for that: you document shared definitions or cross-domain logic once, at the group level, instead of repeating them in every domain that needs them. Approved cross-domain queries follow the same pattern. They're saved to the group's own reviewed query library, not any individual domain's, because a query that spans domains only makes sense in that combined context.

## Create a domain group

1. Navigate to **Domains** and open **Cross-Domain Settings**.
2. Within the Domain Groups section, select the domains you want to include, enter a group name, and click **Create**.

<Note>
  You can also enable **auto-select domain** for your workspace. When enabled, you can start a chat without choosing a domain first, and WisdomAI automatically selects a matching domain if one becomes relevant to your question. This setting applies at the workspace level, separately from domain groups, and includes an allowlist you can configure once enabled.
</Note>

![SCREENSHOT: Domain group creation screen showing domain selection](/images/domain-froups-create.png)

Once the group is set up, you can run queries against it from a new chat. WisdomAI queries all included domains simultaneously and uses each domain's existing [context library](/setting-up-wisdom-ai/context-libraries) when generating a response.

## Add cross-domain context

Each domain in a group brings its own context library. That context explains individual domains, but not how the domains relate to each other. Use the **Manage Context** button to add context at the group level.

![SCREENSHOT: The Manage Context button on a domain group](/images/manage-context.png)

Within **Manage Context**, you can add two types of context:

- **Knowledge**: Add guidance on how to use the combined domains together. For example, explain how datasets connect or which business rules apply across all domains in the group.
- **Reviewed Queries**: The group starts with reviewed queries inherited from all included base domains.

### Cross-domain reviewed queries

When you approve a response within a domain group using thumbs up, WisdomAI saves that query to a separate cross-domain reviewed query library. It does not appear in any individual domain's context library.

To view the cross-domain reviewed query library, navigate to **Cross-Domain Library** \> **Reviewed Queries**.
