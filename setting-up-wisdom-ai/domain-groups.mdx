---
title: "Domain Groups"
---

A domain group lets you combine multiple existing domains and run queries across all of them at once. You can also add shared context to explain how the domains relate to each other.

## Create a domain group

1. Navigate to **Domains** and open **Cross-Domain Settings**.
2. Within the **Domain Groups** section, choose the domains you want to include in the group.

<Note>
  You can also enable **auto-select domain** for your workspace. When enabled, you can start a chat without choosing a domain first, and WisdomAI automatically selects a matching domain if one becomes relevant to your question. This setting applies at the workspace level, separately from domain groups, and includes an allowlist you can configure once enabled.
</Note>

\[SCREENSHOT: Domain group creation screen showing domain selection\]

Once the group is set up, you can run queries against it from a new chat. WisdomAI queries all included domains simultaneously and uses each domain's existing [context library](/setting-up-wisdom-ai/context-libraries) when generating a response.

\[SCREENSHOT/GIF: A query result from a domain group showing data drawn from multiple domains\]

## Add cross-domain context

Each domain in a group brings its own context library. That context explains individual domains, but not how the domains relate to each other. Use the **Manage Context** button to add context at the group level.

\[SCREENSHOT: The Manage Context button on a domain group\]

Within **Manage Context**, you can add two types of context:

- **Knowledge**: Add guidance on how to use the combined domains together. For example, explain how datasets connect or which business rules apply across both domains.
- **Reviewed queries**: The group starts with reviewed queries inherited from all included base domains.

### Cross-domain reviewed queries

When you approve a response within a domain group by selecting thumbs up, WisdomAI saves that query to a separate cross-domain reviewed query library. It does not appear in either individual domain's context library.

To view the cross-domain reviewed query library, navigate to **Cross-Domain Library** \> **Reviewed Queries**.

\[SCREENSHOT/GIF: The cross-domain reviewed query library showing a newly approved query\]
